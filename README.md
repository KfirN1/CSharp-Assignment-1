# C#-Assignment-1

מאגר זה מכיל פתרונות ב-C# ל-10 בעיות אלגוריתמיות מאתר HackerRank, לפי מה שדרוש בחלק א של מטלה 1 קורס פיתוח משחקי מחשב. 

**הערה: בתחילת כל קובץ קוד במאגר מצורף קישור ישיר לעמוד הבעיה המקורית באתר HackerRank.**

## הבעיות שנפתרו
- Bigger is Greater 
- Climbing the Leaderboard 
- Encryption 
- Extra Long Factorials 
- Magic Square 
- Non-Divisible Subset 
- Organizing Containers of Balls 
- Queen's Attack II 
- The Grid Search 
- The Time in Words
